# at PRIVÉ — MK1 → MK2 Roadmap

## MK1
Desktop baseline approved for structural direction.

Focus:
- 7-section home architecture
- Signature 4 program emphasis
- Specialist Medical Access moved down in hierarchy
- A/B/C customer-facing labels removed
- quieter dark/light balance
- editorial typography correction
- no forced title line breaks

## MK2 — Desktop Completion

### 1. Copy de-duplication
Audit the entire home and program detail pages for repeated ideas such as:
- 하나의 / 한 사람
- 프라이빗
- 접근
- 여정
- 선별
- 조율
- 전담
- 건강의 흐름

Each section must have one job:
- Brand: what at PRIVÉ believes
- Service: what at PRIVÉ actually does
- Result: what the client receives

### 2. Home content hierarchy
Keep the home concise:
1. Hero
2. Why at PRIVÉ
3. Three Private Services
4. Four Signature Journeys
5. How the Journey Works
6. Founder & Service Standard
7. Consultation

Do not re-expand specialist programs into a product catalogue on the home page.

### 3. Detail-page hierarchy
For every program:
- Program name is the largest title.
- Value proposition becomes secondary.
- First viewport shows: selected for / expected flow or timeframe / key access.
- Deeper medical explanation stays below the fold.
- Avoid identical template rhythm across all specialties.

### 4. Specialist Medical Access
Preserve content depth without looking like a hospital or treatment seller.
Use:
- decision maps for regenerative medicine / cancer second opinion
- health-system maps for longevity / immune health / brain
- timelines for fertility / recovery / Executive 365
- personal-profile logic for checkup / vision / beauty

### 5. Luxury direction
Luxury should come from:
- restraint
- information hierarchy
- whitespace
- material-like document visuals
- fewer, larger meaningful elements
- confident service language

Avoid:
- excessive gold
- excessive dark panels
- tiny decorative English
- repeated uppercase labels
- generic doctor / stethoscope stock photography

### 6. Founder
Final desktop structure:
- actual portrait
- name / role
- three credibility pillars
- short selected credentials
Do not return to a resume-style qualification dump.

### 7. Final desktop QA before mobile
Check:
- 1920
- 1440
- 1280
- Chrome / Safari
- orphan lines
- accidental hard breaks
- contrast
- repeated copy
- link integrity
- all 14 program routes
- contact CTA consistency

## Mobile
Mobile design begins only after MK2 desktop is approved.
It should be treated as a separate editorial layout, not a scaled-down desktop.
